# Forest Ride 🌲🏍️

**Forest Ride** is a 2D side-scrolling physics-based game built in Unity. This project was created as a heavily modified and expanded version of the Snow Surfer project from Gamedev.tv's *Complete C# Unity 2D Game Development* course.

---

## 🎮 About The Game

**Forest Ride** is an 2D physics-based motorcycle driving game. Players control a bike navigating through rough forest terrains, balancing their bike in the air, performing flips to earn points, avoiding dangerous crashes, collecting coins, and using torque boost power-ups to spin faster along the way to reach the finish line.

The project started as part of the Snow Surfer module from Gamedev.tv's *Complete C# Unity 2D Game Development* course. However, I completely overhauled the graphics and theme from snow to a forest environment, built additional mechanics and expanded it into a mini-game with coin collecting, bike unlocking, pause menu, one more level and cross-platform support.

### 🌟 Key Features
* **New Forest Theme:** New art, environment, and motorcycle sprites replacing the original snow theme.
* **Coin & Unlock System:** Collect coins scattered across levels to unlock a second motorcycle.
* **Multiple Levels:** Includes two distinct levels with unique terrain and challenges.
* **Pause / ESC Menu:** 
  * Resume Game
  * Restart Level
  * Select Bike
  * Select Level
* **Cross-Platform Support:** Plays smoothly on PC (keyboard) and Mobile devices (touch buttons).

| Action | PC Controls | Mobile Controls |

| **Boost / Accelerate** | Up Arrow Key (or W) | On-screen Boost Button |
| **Pause Menu** | ESC Key, Pause Button | Pause Button |
